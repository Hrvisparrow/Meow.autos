# Meow Autos

Statička web stranica za Meow Autos — mobilni servis vozila, strojeva i opreme.
Održavanje motornih vozila, asistencija u cestovnom prometu i tehnička podrška u autosportu.

## Sadržaj repozitorija

| Datoteka | Opis |
|---|---|
| `index.html` | Cijela stranica (HTML + Tailwind CDN + inline CSS/JS) |
| `logo.jpg` | Logo / maskota |
| `.nojekyll` | Isključuje Jekyll obradu na GitHub Pages |

## Lokalni pregled

Otvori `index.html` u pregledniku, ili posluži mapu preko lokalnog servera.

## Objava (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)`.
Stranica je zatim dostupna na `https://<korisnik>.github.io/Meow.autos/`.
